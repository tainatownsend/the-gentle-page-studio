# Gentle Page Editorial Design System v1

This document defines the publication-facing visual language used by Gentle Page Studio. It is intentionally separate from the Studio application UI design system.

## Product rule

The generated journal must look intentionally composed before the user makes any layout adjustment.

## Visual character

- calm, adult, warm, and premium
- supportive rather than clinical
- lightly expressive rather than decorative
- structured enough for worksheets and planners without feeling corporate
- whitespace is intentional, never an unresolved layout artifact

## Palette

- Paper: warm off-white `#FCFAF6`
- Ink: soft charcoal `#2B302D`
- Muted ink: `#6B746E`
- Sage: `#7A9080`
- Deep sage: `#53685B`
- Soft sage: `#E8EEE9`
- Clay: `#B98575`
- Soft clay: `#F2E6E1`
- Sand: `#D6C39E`
- Soft sand: `#F3EDDF`
- Mist: `#E9EEF0`

Color is used for hierarchy, grouping, navigation, and gentle emphasis. It should not turn the publication into a rainbow planner.

## Typography

- Display: warm editorial serif
- Body: clean sans-serif
- Section titles should feel like editorial openings, not generic web headings.
- Prompts and worksheet labels use stronger sans-serif weight for clarity.

## Core components

### Cover

- serif publication title
- small Gentle Page brand capsule
- restrained sage and clay accents
- warm paper background
- decorative elements must never compete with the title

### Section heading

- soft sage field or accent rail
- deep-sage text
- enough spacing to establish a new editorial beat

### Subheading

- compact clay accent
- readable, not oversized

### Prompt + response

- prompt is visually grouped with its response area
- response area uses warm field fill and subtle writing guidance
- short/medium/long remain semantic size intents

### Rating

- contained soft-sage panel
- controls use sage rather than black borders

### Tables / worksheets

- soft-sage header row
- subtle warm alternating rows
- semantic response and checkbox controls must render as controls, never compiler syntax

### Footer

- restrained page number with a short rule

## Static / fillable parity

Static print output and fillable PDF output must share the same editorial language. Fillable controls are overlays on the publication design, not a separate visual product.

## Next layer

Page archetypes and compound journal recipes should consume these tokens rather than introducing ad-hoc visual styles.
