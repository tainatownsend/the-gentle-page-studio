## Canonical acceptance pages

These pages define the production visual standard:
- Cover
- 4-State Self-Scan
- Emergency Unfreeze Protocol
- Daily Check-In

Future pages should look like extensions of these references, not new visual explorations.

## Page rules

### Cover
- Editorial botanical composition.
- Title is the focal point.
- Brand is secondary.
- No tabs.

### 4-State Self-Scan
- Four clearly differentiated state modules.
- High legibility.
- Restrained functional state colors.
- No tiny type.

### Emergency Unfreeze Protocol
- Must fit on one page.
- Clear numbered vertical sequence.
- Rapid scanning while cognitively overloaded.
- Final next step receives dedicated writing space.

### Daily Check-In
- Scales align mathematically.
- Comfortable tablet touch targets.
- Reuse lower-page space for intention / notes.
- No wasted lower-half whitespace.

### Writing / Reflection
- Writing area is the hero.
- Prompt area should stay compact.
- Decoration is peripheral.

### Weekly / Planning tools
- Grid is the hero.
- Cells remain writable.
- Exact row / column alignment.
- Decoration stays out of high-use zones.

## Production gates

1. Reproduce canonical acceptance pages.
2. Extend the approved system to all remaining pages.
3. Run alignment, spacing, pagination, tablet, print/grayscale, typography, and content-fidelity QA.
4. Generate printable PDF.
5. Generate fillable / tablet-friendly PDF.
6. Produce listing previews and product thumbnails.

## Definition of done

The full product is ready only when the pages read as one coherent editorial publication and no regression from the approved visual North Star remains.
