# Gentle Page Studio North Star Status

## North Star

**Paste → Compile → Preview → Export**

The compiler should make layout decisions. The user should correct exceptions with semantic controls rather than reconstructing the publication block by block.

## Implemented

- manuscript-first publication creation;
- Gentle Page Manuscript Protocol v1;
- compiler output into durable publication blocks;
- direct compile-to-preview path;
- preferred and forced page-break intent;
- heading look-ahead and orphan prevention;
- response-size intent;
- elastic response-field expansion into safe spare page capacity;
- semantic correction controls for response size and page placement;
- derived layout health diagnostics;
- browser/fillable-PDF allocation parity;
- manual block editor retained as an advanced fallback.

## Remaining toward the full North Star

- first-class tables and matrices;
- rating-scale fields;
- semantic checkbox groups / worksheet groups;
- repeatable pages;
- `.docx` ingestion with structure preservation;
- deeper multi-pass cross-page rebalancing;
- optional targeted compiler suggestions;
- golden-manuscript benchmark automation using real journal fixtures.

The product direction remains: **automatic composition for the common case, small semantic interventions for exceptions.**
