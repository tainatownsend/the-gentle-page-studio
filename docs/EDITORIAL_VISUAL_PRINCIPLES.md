# Editorial visual principles

1. Color communicates hierarchy and grouping; it does not decorate every block.
2. Warm paper replaces clinical white where possible.
3. Section changes must create a recognizable editorial beat.
4. Prompts and response areas are one visual unit.
5. Planner tools and worksheets should read as tools, not as paragraphs followed by empty space.
6. Fillable controls inherit the publication aesthetic.
7. Whitespace is intentional only when the composition makes its purpose visible.
