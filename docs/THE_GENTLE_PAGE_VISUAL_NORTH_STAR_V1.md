# The Gentle Page — Visual North Star v1

Status: APPROVED / LOCKED  
Primary collection for The Steady State: **Collection A — Calm & Classic**

## Brand direction

The Gentle Page should feel calm, practical, kind, empowering, clear, and beautiful. The publication should read as a premium editorial workbook rather than generated app UI.

## Collection A — Calm & Classic

Use for evergreen tools, self-regulation, nervous-system work, and core Gentle Page products.

Core colors:
- White — `#FFFFFF`
- Sage — `#6B7F72`
- Moss — `#A7B8A8`
- Ivory — `#F9F7F2`
- Clay — `#E2D3C7`
- Charcoal — `#2F3A36`

Supporting functional tints may be used sparingly for state differentiation, but Collection A remains visually dominant.

## Non-negotiable layout rules

- Pure white page background.
- One consistent master grid and outer margin system.
- Exact alignment across titles, prompts, controls, tables, and writing areas.
- Generous handwriting / Pencil space.
- Typography and proportion create hierarchy before color does.
- Botanicals live at edges or corners and never compete with usable space.
- No accidental dead space.
- Dense content must be restructured rather than shrunk.
- All repeated controls use identical dimensions and spacing.
- Printable and tablet-friendly.
- Grayscale-safe.

## Explicit rejection

Do **not** use side tabs, vertical edge tabs, pseudo-binder tabs, or decorative navigation tabs. A prior acceptance mockup contained corrupted/nonsensical labels in those tabs; the founder approved the same composition only after the tabs were removed.

Also reject:
- corrupted or placeholder text
- random language switching
- app-like dense card grids
- arbitrary component sizes
- nearly-aligned elements
- raw Markdown / HTML / internal directives
- decorative clutter

## Canonical page families

- Cover / Minimal Editorial
- Table of Contents / Navigation
- Section Opener
- Prompt + Writing
- Daily Check-In
- Emergency / One-Page Protocol
- Weekly Reset
- Planner / Tracker
- Table / Matrix / Framework
- Closing / Return Page

## Quality bar

Every page should look like it belongs to the same physical publication. The finished product must feel designer-made, editorial, kind, premium, highly usable, visually consistent, and commercially ready.
